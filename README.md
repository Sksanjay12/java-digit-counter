# Java Digit Counter

This repository contains a simple Java program that counts the number of digits in an integer using a loop.

## Code Explanation
- The program divides the number by 10 repeatedly until it becomes 0.
- Each division removes one digit, and a counter tracks the number of steps.
- Example: `1234 → 123 → 12 → 1 → 0` → 4 digits.

## How to Run
1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/java-digit-counter.git
Compile the program:
javac Main.java
Run the program:
java Main
Output:
